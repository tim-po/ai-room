# Independent content decision guide

Direction033 reviewer support. This guide grants no approval. The worker owns
integration and the final private cumulative export from a protected copy of
current staged data. Name that candidate SHA, package hash and content ledger in
every decision. Staged `dae0217` with three foundation A forms is a different
review target from the pending ten-revision/source-reader candidate.

Keep keyed packages private (mode0600). Publish only sanitized verdicts and
hashes. Do not reuse turn026's synthetic-state approval hash on retained state.

## Four separate decisions

| Decision | Exact review unit | What acceptance permits | What it does not establish |
| --- | --- | --- | --- |
| Teaching and mapping | `manifest.curriculum.sha256`, ten complete before/after rows, objective scopes, graph and parent publication context | Scheduled installation of those source revisions and teaching mappings | Understanding, video watched, applied competence, or assessment approval |
| Original full-form confirmation | Each relevant `manifest.retained_forms` ID, complete keyed body and export digest; retain its original publication identity | A stated narrow interpretation of the original form after source, distractor, explanation and coverage review | Equivalence to another form or new publication permission |
| Transfer correctness and equivalence | Each final `transfer_publication_candidates[].sha256`, full form, source edition/hash, lesson/access binding; compare original form explicitly | A separate correctness decision and, only if justified, a named original/transfer equivalence decision | General proficiency, automatic retake credit or practical achievement |
| Applied rubric sufficiency | Mobile/tools `practical_sha256`, complete instructions and criteria, proposed assessment/objective binding | A decision that an observable submission could support the stated narrow applied claim | Any learner passing without submission and human criterion review |

These are independent verdicts. Record `accept`, `revise` or `reject` with reasons
for each unit; absence of a decision is pending. A correctness acceptance must
not silently fill the equivalence decision. The exporter records an operator
identity, not a semantic reviewer verdict.

The private package includes all retained forms, which may exceed the seven
original specialist examples once current staged foundation forms are copied.
Identify original forms by their IDs and actual body; do not assume every retained
form is one of those seven or derive their identity from list position.

## Evidence required for the practical proposals

The existing proposals in `club/transfer_candidates.py` already request observable
artifacts. Review the exact exported wording before accepting; the rows below
explain its intended narrow scope without changing its hash.

| Proposal / criterion | Observable evidence needed |
| --- | --- |
| mobile / artifact | Accessible versioned source or diff showing unavailable-microphone handling |
| mobile / permission | Actual run log showing first launch without a request, recording after consent, and refusal with file upload retained |
| mobile / revocation | Reproducible permission revocation and reopening run: no crash, unavailable microphone handled, file upload still available |
| mobile / scope | Change and observed requests add no contacts or other permissions; report distinguishes tested and untested environments |
| tools / validator | Executable server validation rejects unknown task IDs and extra fields before reading; actual negative tests and code |
| tools / response | Both allowed synthetic IDs return only a status in the specified set; actual positive tests |
| tools / injection | Malicious note test produces no write; matching before/after state and log with no mutation call |
| tools / reproduce | Version, run command and actual positive/negative results sufficient for repetition |

A prose promise, planned test, inaccessible artifact or uncertain outcome cannot
meet a criterion. A submitted URL alone is not verification. Human review must
assess all criterion IDs against the pinned submission/rubric; `uncertain` and
`not_met` prevent application credit. Mobile covers microphone permission and
revocation in the synthetic case, not broad mobile engineering. Tools covers the
synthetic read-only boundary, not unrestricted agent security.

Practical proposals intentionally omit `assessment_id` and `confirm_reviewed`.
If approved, identify the real assessment/objective binding and inspect the final
pinned rubric before manager-scheduled publication. Instruction, criterion or
binding changes require fresh review; do not treat the proposal hash as a digest
of the subsequently published runtime rubric.

## Exact identities and review record

The package/curriculum/retained-form export digest uses compact sorted UTF-8 JSON.
Transfer and practical digests use sorted UTF-8 JSON with default separators.
Use exporter-provided hashes; do not compare different serialization conventions.
A retained-form export digest does not replace its original publication hash.
Final transfer hashes bind learner source URLs, form ID, lesson and access; an
unbound or editorial-source hash cannot approve the final learner form.

For each review unit, record: candidate SHA, content-ledger identity, package
hash, unit ID/hash, reviewer identity/role, verdict, exact accepted claim, source
support, ambiguity/coverage findings and required changes. For equivalence also
record both form identities, construct/difficulty comparison and exposure/retake
limits. For practical sufficiency record the objective/binding and all observable
criteria. Keep answers and protected source text out of the public decision record.

Passing structural tests, installing source snapshots, a 39/70 mapping count or
exporting a bundle is not semantic acceptance. Retake lineage/exposure protections
remain necessary even after equivalence approval. The three staged foundation
A forms retain their existing authorization; this guide does not republish them.
Real-provider spoken-video/material processing, novice-teacher acceptance and
independent staged reviews remain separate release gates.
